# GPU environment for P6 (TextFooler test set) and P8 (training variants): `.venv-p6`
# (git-ignored), separate from the project's `.venv`. Versions below are the ones tested on the
# 24 GB RTX 5090 laptop (2026-11-26). Build it with:
#
#   uv venv .venv-p6 --python 3.12
#   $env:VIRTUAL_ENV=".venv-p6"   (bash: export VIRTUAL_ENV=.venv-p6)
#   uv pip install torch --index-url https://download.pytorch.org/whl/cu130
#   uv pip install -e . -r requirements/p6-textfooler.txt
#   uv pip install --no-deps textattack==0.3.11
#   .venv-p6/Scripts/dataset-builder p8-variants        (or p6-textfooler)
#
# Notes:
#  - Shieldstral needs transformers 5 (model type ministral3). TextAttack is installed WITHOUT its
#    dependencies: its flair dependency pins transformers<5. TextFooler does not use flair (its
#    part-of-speech check uses NLTK); steps/p6_attack.py registers a stand-in that fails loudly if
#    anything calls flair.
#  - gpt-oss-20b (judge) ships MXFP4 weights (about 13 GB). transformers accepts `kernels`
#    >=0.18.2,<0.19 only; without it the weights are expanded to bf16 (about 40 GB) and do not fit.
#    The judge checks this before loading.
#  - Qwen3-14B (P8 generator) is 28 GB in bf16: it loads in 8-bit with bitsandbytes (about 15 GB).
#  - The model weights are in models/ (git-ignored), downloaded once at the revisions in the config.
