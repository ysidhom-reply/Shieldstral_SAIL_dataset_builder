# P6 (TextFooler against base Shieldstral) runs in its own isolated uv environment on the GPU
# machine, because TextAttack needs transformers<5 (hence huggingface-hub<1), while the project
# lock uses huggingface-hub 2.x (P5, P10). Run:
#   uv run --isolated --no-project --with-editable . --with-requirements requirements/p6-textfooler.txt dataset-builder p6-textfooler
#
# Also needed, outside this file:
#  - a CUDA build of torch matching the driver (install it first, see pytorch.org);
#  - the judge (gpt-oss-20b) is loaded in the step from `textfooler.judge_path`. Its weights are
#    MXFP4: without the MXFP4 kernels (packages `kernels` and triton; `triton-windows` on Windows)
#    transformers expands them to bf16 (about 40 GB), which does not fit a 24 GB GPU.
#    transformers accepts kernels >=0.18.2,<0.19 only; the judge checks this before loading.
#  - the weights in models/ (git-ignored), downloaded once at the revisions pinned in the config.
#
# OPEN: Shieldstral may need a newer transformers than TextAttack allows. If the first GPU run
# cannot load it here, score with Shieldstral in the same environment only after checking its model
# card, or run the attack with a surrogate and measure the transfer (see the P6 plan).
